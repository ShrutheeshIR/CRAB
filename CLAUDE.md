# Working agreement

- Never run code: no python, cmake, bazel, make, lint, or test commands. The user
  builds/runs/tests everything themselves. Only read, write, and edit files.
- Be concise. No elaboration, no restating the task, no verbose summaries.
- Minimize tokens: avoid re-reading files already in context, avoid re-explaining
  code that speaks for itself, skip preambles/postambles, prefer terse edits over
  regenerating whole files.
